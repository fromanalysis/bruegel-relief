# Painting to Bas-Relief — a build diary

Turning Bruegel's *Hunters in the Snow* into a 3D-printed bas-relief:
monocular depth estimation, a conditioned heightfield, and an FDM printer —
documented as a diary of what worked, what failed in plastic, and why.

- **[The build guide / diary](https://fromanalysis.github.io/bruegel-relief/)** — the main page
- [The Poisson solve, for dummies](https://fromanalysis.github.io/bruegel-relief/poisson.html) — side note
- [From relief to sculpture](https://fromanalysis.github.io/bruegel-relief/painting_to_sculpture.html) — Branch B roadmap

Everything is hand-typed Python (numpy/scipy/trimesh + Depth Anything V2) on an
Apple Silicon Mac, printed on a Bambu A1 mini. The pages are single
self-contained HTML files; no build step.
